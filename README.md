# 📱 Google Play Store Apps: Exploratory Data Analysis

An end-to-end exploratory data analysis of Google Play Store apps, covering data cleaning, EDA, feature engineering, and insights on app categories, pricing, ratings, and installs.

---

## 📌 Project Overview

This project explores what drives app popularity on the Google Play Store. It cleans a raw dataset, analyses it at univariate, bivariate, and multivariate levels, and prepares the data for machine learning tasks.

---

---

## 🚀 Project Workflow

### 1. Data Understanding & Cleaning
- Imported and explored the dataset
- Handled missing values, duplicates, and incorrect datatypes
- Standardized features (converted Installs, Reviews, and Size to numeric values)

### 2. Exploratory Data Analysis (EDA)
- **Univariate:** distribution of ratings, installs, reviews, and app sizes
- **Bivariate:** rating vs installs, price vs reviews
- **Multivariate:** correlation heatmaps across multiple features

### 3. Feature Engineering
- Encoded categorical features (Category, Type, Content Rating, Genres)
- Created derived features (e.g. log-transformed installs)
- Scaled numerical values for ML readiness

### 4. Insights & Visualization
- Most popular app categories
- Free vs paid apps analysis
- Relationship between price and popularity
- Heatmaps, histograms, bar charts, and scatter plots

### 5. ML Preparation (Optional Extension)
- Prepared the dataset for classification and regression tasks (e.g. predicting ratings or installs)

## 📈 Key Insights

- 📌 **Family, Game, and Tools** dominate the app categories.
- 📌 **Free apps** have significantly higher install counts than paid ones.
- 📌 Ratings skew towards **4.0 to 4.5**, indicating general user satisfaction.
- 📌 **Paid apps** don't always guarantee better ratings.
- 📌 **Heavy apps** (large size) are not always more popular.
